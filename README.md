# L'Équipage · Séance à deux

Le site de L'Équipage pour choisir quoi regarder ou quoi jouer quand personne n'arrive à se décider.

- **Soirée film** : environ 300 films, des comédies cultes françaises aux pépites méconnues.
- **Soirée jeux Steam** : 84 jeux jouables en ligne entre potes.
- De 2 à 6 personnes : chacun répond à son tour, le site croise les envies et explique pourquoi chaque proposition vous correspond.

Tout tient dans `index.html` : pas de serveur, pas de compte. Les prix des jeux sont indicatifs (hors promo) et les durées des films viennent de données compilées à la main.

## Bot Discord

Le dossier `bot/` contient le bot de L'Équipage : `/soiree film` ou `/soiree jeux`, questionnaire en privé pour chacun, puis verdict posté dans le salon. Il partage le moteur du site. Installation et lancement : voir [`bot/README.md`](bot/README.md).
